## 🧭 About me

I'm **Daniil**, an **ML Product Manager** with a background in building software. I'm interested in the intersection of **user needs, machine learning, and product decisions** — where a technical possibility becomes something people actually use.

I like turning ideas into tangible things: prototypes, interfaces, integrations, and tools. This GitHub is a collection of that hands-on work, from API experiments to personal products.

- 🎯 **Product first:** start with the problem and define what a useful outcome looks like.
- 🧠 **ML with a purpose:** explore where AI can improve a real user workflow.
- 🛠️ **Make it tangible:** use prototypes to make ideas easier to test and discuss.
- 📊 **Learn and iterate:** connect feedback and measurement to the next product decision.

## 🔎 My product lens

| Discover | Build | Learn |
| :--- | :--- | :--- |
| Understand the user and the problem | Turn a hypothesis into a working prototype | Check whether it creates value |
| Find a meaningful use case for ML | Consider data, quality, and UX together | Use evidence to choose the next step |
